# Ray Facts: sources

Every fact in `Sources/RaynaCore/RayFacts.swift` is tagged with a source key. Facts are deliberately conservative (rounded numbers, "about", "can") and were cross-checked against these references (October 2026).

| Key | Source |
|---|---|
| NOAA-manta | NOAA Fisheries, *Giant Manta Ray* species page (wingspan up to 26 ft, lifespan up to 45 yrs, pup ~6 ft at birth): https://www.fisheries.noaa.gov/species/giant-manta-ray and the NOAA manta/devil ray ID guide (2025) |
| NOAA-devil | NOAA Fisheries manta and devil ray identification (the same ID guide as NOAA-manta): cephalic fins beside a terminal mouth, a plankton diet, no stinging barb, a dark dorsal surface, and live young. The skate "mermaid's purse" contrast uses SharkTrust-eggcase. Schooling uses NatGeo-mobula. The sentence about a Halloween cape is Rayna's wording on the dark-wing fact, not a quotation. |
| NOAA-sawfish | NOAA Fisheries, *Smalltooth Sawfish* (first native marine fish listed under the ESA, 2003; rostrum senses and slashes prey): https://www.fisheries.noaa.gov/species/smalltooth-sawfish |
| NOAA-largetooth | NOAA Fisheries, *Largetooth Sawfish* (enters freshwater; up to ~7 m): https://www.fisheries.noaa.gov/species/largetooth-sawfish |
| NOAA-cownose | NOAA Fisheries / NOAA Chesapeake Bay Office, cownose ray migrations along the US Atlantic coast |
| NOAA-shuffle | NOAA Ocean Service, "stingray shuffle" safety advice |
| FLMNH-torpedo | Florida Museum of Natural History, *Atlantic Torpedo* (kidney-shaped electric organs; 170–220 V): https://www.floridamuseum.ufl.edu/discover-fish/species-profiles/atlantic-torpedo/ |
| FLMNH-eagle | Florida Museum, *Spotted Eagle Ray* (duck-bill snout, plate-like teeth, leaping) |
| FLMNH-stingray | Florida Museum, *Southern Stingray* / stingray biology (barb is a modified dermal denticle that is replaced; live birth with histotroph) |
| FLMNH-river | Florida Museum, freshwater stingrays (Potamotrygonidae) of South America |
| Smithsonian | Smithsonian Ocean, *Sharks & Rays* overview (cartilage skeletons, elasmobranchs, >600 batoid species, electroreception, spiracles, history of the torpedo name and Roman medical use): https://ocean.si.edu/ocean-life/sharks-rays |
| SharkTrust | The Shark Trust species guides (mantas lack a sting; guitarfish): https://www.sharktrust.org |
| SharkTrust-eggcase | The Shark Trust *Great Eggcase Hunt* (skate "mermaid's purses"): https://www.sharktrust.org/great-eggcase-hunt |
| MantaTrust | The Manta Trust (unique belly spot patterns for photo-ID, cleaning stations, cephalic fins, large brain-to-body ratio): https://www.mantatrust.org |
| NatGeo-mobula | National Geographic, mobula (devil) ray aggregations and leaping in the Gulf of California |
| NatGeo-giantfw | National Geographic, giant freshwater stingray (*Urogymnus polylepis*), one of the largest freshwater fish |
| AustMuseum | Australian Museum, *Blue-spotted Fantail / Ribbontail Ray* (Indo-Pacific reefs) |
| Aquarium-shovelnose | Aquarium of the Pacific / Monterey Bay Aquarium, *Shovelnose Guitarfish* (shallow sandy habitats off California) |

Before adding a fact, check it against at least one of these (or a similarly reputable source) and add its key.
