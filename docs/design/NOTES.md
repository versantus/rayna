# Rayna main screen declutter mockups (17 Oct 2026)
iPhone 13, 390x844 pt rendered @2x (780x1688). HTML/CSS in src/, rendered with headless Chrome (src/shot.sh a b c).
Art: real stills from /workspace/rayna-art (band1/band2/band3) + one badge overlay each (over7 rosette, over30 crown, personalBest trophy).
Each mockup shows a different progress state (16% / 63% / 84%) so the mood stills vary.

A Hero: Ray ~80% wide in a top-half "glass" card with the water level inside (16%). Message becomes Ray's speech bubble; streak dots shrink under the title; amount is one line; bottom dock holds +1 glass (size pill inside the button), undo, and Pod + Exercise chips.
B Immersive: full-bleed ocean, the whole screen is the glass and the water line is progress (63%). Amount top-left with tiny streak; Pod (3/4), Exercise (+500, on), Trophy, Settings as a 2x2 icon cluster; floating white +1 glass with undo left and size picker right.
C Balanced: large pool card (Ray ~78% wide) with speech bubble and % ring inside; amount line; one compact row with pod avatars (green ring = on track) + exercise toggle; split button (size picker | +1 glass) plus undo.

The built app does not include the Exercise toggle, the +500 control, or the "Exercise adds +500 ml" line shown in these pictures. Exercise days live in Settings.
